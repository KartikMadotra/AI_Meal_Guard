# AI MealGuard Team Handover Documentation

Welcome to the AI MealGuard Team Handover Documentation. 
This project is an AI-powered smart monitoring system for nutritious school meals, designed with a focus on UN Sustainable Development Goal (SDG) 2: Zero Hunger.

## Usage
Simply open `index.html` in any modern web browser to access the interactive documentation.

The documentation is organized logically to cover:
1. The **Problem & SDG 2 Impact**
2. Our **Solution & Innovations**
3. The **AI Pipeline & Model (YOLO Segmentation)**
4. **Nutrition & Scoring Logic**
5. **Interactive Data Examples**

## Project Structure
- `index.html`: The main documentation entry point.
- `mealguard.css`: The styling file powering the UI.
- `mealguard.js`: The interactivity logic (charts, simulators, navigation).

Enjoy exploring the AI MealGuard project!
